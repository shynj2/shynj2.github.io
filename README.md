# Shayan Mirkhani — A Song of Ice & Code

Interactive 3D resume (React + Three.js + Vite).

## Deploy on GitHub Pages
1. Push this project to a repo's `main` branch.
2. Repo → Settings → Pages → Source: **GitHub Actions**.
3. Every push builds and publishes automatically.

For this to be your main page at `https://USERNAME.github.io/`, name the repo `USERNAME.github.io`.

## Local
```
npm install
npm run dev
npm run build
```
